# DSH-Custom-Compact

为当前 profile 的所有会话提供共享的压缩模型、思考强度和自动压缩阈值设置。插件复用原生摘要提示词、压缩事务、工具配对边界、事件记录和持久化，不复制整份压缩后端或会话预设。

## 安装与入口

本目录是可直接安装的本地 bundle，无需构建或额外安装 React。宿主核心通过 peer 依赖复用；本地目录安装后需要保留此仓库。

在插件管理器选择本地 bundle 目录，或在另行授权安装的会话中执行：

```text
plugin_manager
  action: install_bundle
  target: E:\others\Projects\DSH-Plugins\DSH-Custom-Compact
```

安装行为会更改当前 profile，本次开发没有执行安装。安装结果要求 `application: applied` 才表示已应用；如果提示重启，按结果要求处理，再刷新现有 GUI。不要另外启动 Web 服务器。

安装后，选择已有内容的会话，上栏会出现 **DSH-Custom-Compact** 标签。窄窗口可能折叠进 `…`；空白会话隐藏标签属于宿主行为。设置在所有会话、窗口之间共享，保存冲突保留草稿。设置表单的 entry id 固定为 `custom-compact`，不要改名或重复插入。

## 设置与命令

| 项目 | 行为 |
|---|---|
| 压缩模型 | `/compact` 和原生自动压缩使用所选 provider/model；空值使用当前会话主模型。 |
| 思考强度 | 从所选模型支持的值中选择；默认不指定，由适配器解析。切换模型时清除不支持的旧强度。 |
| 百分比 | `floor(min(W × 百分比 / 100, W − 输出预留 − 安全余量))`，保留原生安全余量；空值沿用原生既有策略。 |
| 绝对 tokens | 空值或 `T ≥ W` 沿用原生策略；`0 < T < W` 严格使用 `T`，不再按百分比或安全上限压低。 |
| `/defcompact` | 无参数，强制使用当前会话主模型；不应用自定义压缩模型的强度，沿用主模型显式强度或适配器默认值。 |
| `custom_compact_settings` | 模型可调用的设置工具：`get` 返回配置、revision 和当前会话状态；`set` 保存提供的字段，不触发压缩。 |

两种模式互斥，但保留未选中模式的有效输入值。所有字段为空时使用主模型及原生阈值策略，不把宿主默认值写死。每次压缩捕获一份配置，新设置不改变进行中的摘要或同次压力压缩的重试。

`W` 来自被检查的会话主模型；模型切换检查使用目标主模型窗口，不使用摘要模型窗口。过低阈值可能低于系统提示、工具和不可拆分历史的开销。必要时降低近期保留预算，但不拆开工具调用与结果；压缩无法继续缩减时按原生流程报告或记录失败，不无限重试。

## 原生复用与限制

- 适配依据宿主 `0.2.2-rc.1`、Cordis `4.1.0`。主要入口为公开的 `compactIfNeeded`、`compactNow`、`compactRegion`。
- **必要的非公共适配只有具体后端的 `compactPressure` 入口**：原生模型切换直接调用它，严格绝对阈值必须覆盖该路径。实例包装与绝对压力范围选择集中在[适配器](<host/native-adapter.js>)，不修改宿主文件或类原型。
- 只适配结构兼容且未被其他插件改写的原生 `BasicCompactionEngine`；自定义后端或被覆盖的摘要钩子不会强行套用。界面和设置工具显示适配状态，未接入时保留原生行为。
- 未关闭原生自动压缩，也不擅自打开已经关闭的自动压缩。provider 确认的上下文溢出恢复继续复用原生路径。
- 摘要输出上限、摘要错误恢复及 provider 重试仍由原生后端/适配器控制。模型不可用、认证失败、强度不支持或摘要不够小不会静默切换模型。
- 配置写入复用 Settings / ConfigEditor。只读状态接口通过公开 Connection RPC 调用带协议标记的 Host 方法，不自建鉴权、HTTP 服务或客户端设置存储。
- 宿主升级后若方法或配置结构不匹配，会拒绝部分接入；升级适配集中处理该模块，不重写完整预设。结构检查不等于对未来版本行为的保证。
